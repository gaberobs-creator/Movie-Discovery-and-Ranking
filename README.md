# Movie Discovery and Ranking

This repository includes the MovieLens **ml-latest-small** dataset for development and experimentation.

- Extracted CSV files: `data/ml-latest-small/`
- Original archive: `data/ml-latest-small.zip`
- Source: <https://grouplens.org/datasets/movielens/>
- Archive SHA-256: `696D65A3DFCEAC7C45750AD32DF2C259311949EFEC81F0F144FDFB91EBC9E436`

The dataset contains 100,836 ratings and 3,683 tags across 9,742 movies, from 610 users.

See `data/ml-latest-small/README.txt` for file schemas, citation information, and usage terms.
